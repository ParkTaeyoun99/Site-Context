# 공통 규칙 목록 — 건축사 시험 대지계획에서 추출

출처: 2026년 제2회 건축사 자격시험 대지계획 (1과제 배치계획, 2과제 대지분석·대지주차) 문제와
한솔아카데미 모범답안(안)·체크주안점. 학원 답안이라 공식 정답이 아니며, 해석은 출처마다 다를 수 있다.

규칙은 세 종류로 나눈다.

- **A. 법규·기하 규칙**: 누가 풀어도 같은 답이 나온다. 도구가 자동으로 계산한다.
- **B. 계획 원칙**: 판단이 들어가지만 시험이 반복해서 요구한다. 배치 대안을 만들 때 점수 기준으로 쓴다.
- **C. 과제 조건**: 문제마다 주어지는 값이다. 도구에서는 입력칸이 된다.

상태: ✅ 도구에 있음 · 🛠 이번에 추가 · ⏳ 다음 단계 (평면·배치 대안)

### 2과제 모범답안에서 읽은 판단 순서

1. 3m 도로 → 0.5m 확폭, 6m×3m(확폭 후 4m) 모퉁이 → 가각 2m×2m. 그다음 이격거리(도로 2.0m, 인접대지 1.5m)를 적용한다.
2. 지상 연면적 = 880 × 250% = 2,200㎡. 1층 갤러리 상부 오픈 80㎡를 더해, 5개 층 × 456㎡에서 80㎡를 뺀 값으로 맞춘다.
3. 바닥 456㎡의 단변을 16m(주차 5 + 차로 6 + 주차 5)로 정하고, 장변은 456 ÷ 16 = 28.5m가 된다. **주차 모듈이 매스 폭을 정한다.**
4. 매스를 북쪽(지반이 높은 쪽)에 붙인다. 그러면 지하층 둘레의 가중평균 지표면이 +1.15m가 되고, 지하층 바닥(1층 +3.0 − 층고 4 = −1.0)에서 2.15m로 층고의 1/2(2m) 이상이 된다. 그래서 **지하층으로 인정되고 용적률에서 빠진다.**
5. 건폐율은 51.82%로 한도 60%보다 작다. 규모는 용적률과 층수 상한이 정했다.

대안 2·3은 동쪽 이격 해석(2.5m 대 2.0m)과 매스 비례만 다르고, 판단 순서는 같다.

## C. 과제 조건 → 도구 입력

용도지역, 건폐율·용적률, 층수 상한, 층고, 1층 바닥 레벨, 이격거리(도로·인접대지), 건축한계선, 주차 기준(시설면적 ㎡당 대수), 주차 형식, 경사로 기울기.

## 검증: 2과제 재현

시험 대지(20.5 × 44.1m, 3m·6m·8m 도로, 북쪽으로 3m 오르는 지형)를 가상 프로젝트로 만들어 도구로 풀었다.
조건은 2종일반주거, 건폐율 60%, 용적률 250%, 층고 4m, 지상 5층 이하, 1층 바닥 +3.0m, 이격은 도로 2m·인접대지 1.5m,
북측 도로 건축한계선 5m, 외벽 일치, 지하주차 모듈, 주차 150㎡당 1대로 넣었다.

| 항목 | 모범답안 (대안 1 / 3) | 도구 |
|---|---|---|
| 대지면적 (확폭·가각 제외) | 880㎡ | 880.0㎡ |
| 확폭 / 가각전제 | 0.5m / 2m × 2m | 0.5m / 2m × 2m |
| 지상 연면적 · 용적률 | 2,200㎡ · 250% | 2,200.0㎡ · 250.00% |
| 매스 | 16 × 28.5m, 북측 한계선에 붙임 | 16 × 27.5m, 북측 한계선에 붙임 |
| 지하층 가중평균 지표면 | +1.15m / +1.17m → 지하층 | +1.17m → 지하층 |
| 주차대수 | 15대 | 15대 |

남은 차이(바닥 456㎡ 대 440㎡)는 갤러리 2개 층 높이 상부 오픈 80㎡ 조건이 도구에 없어서다.
